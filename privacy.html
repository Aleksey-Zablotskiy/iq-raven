2. Какие данные обрабатывает приложение

Приложение предоставляет пользователю визуальные логические задания. Для прохождения теста пользователь выбирает варианты ответов, после чего приложение рассчитывает результат.

Разработчик не запрашивает у пользователя имя, фамилию, номер телефона, адрес электронной почты, учётные данные или платёжную информацию. В приложении не предусмотрена регистрация пользовательской учётной записи.

Ответы на задания и результат теста используются для работы приложения. Они не передаются разработчику через собственный сервер приложения.

3. Рекламные сервисы Яндекса

В приложении используется рекламный SDK Яндекса (Yandex Mobile Ads SDK) для показа рекламы. SDK предоставляется компанией Яндекс и может обрабатывать технические сведения об устройстве и взаимодействии с рекламой.

В зависимости от версии SDK, настроек приложения и доступных разрешений могут обрабатываться:

  • рекламные идентификаторы устройства и другие технические идентификаторы;
  • IP-адрес и сведения, необходимые для сетевого взаимодействия;
  • информация об устройстве, операционной системе и параметрах подключения;
  • сведения о показах рекламы и взаимодействии с рекламными материалами.

Эти сведения используются для предоставления, показа и оценки эффективности рекламы, а также для обеспечения работы рекламной системы и предотвращения недействительных рекламных действий.

В стандартной конфигурации Yandex Mobile Ads SDK не собирает точное и приблизительное местоположение самостоятельно. Передача сведений о местоположении может быть включена разработчиком отдельно при наличии необходимых разрешений и согласия пользователя.

Разработчик приложения не использует рекламные данные для самостоятельного создания пользовательских профилей.

Подробнее об обработке данных рекламными сервисами Яндекса можно узнать в Политике конфиденциальности рекламных сервисов Яндекса и в документации Yandex Mobile Ads SDK для Unity .

4. Передача данных третьим лицам

Разработчик не продаёт и не передаёт пользовательские данные третьим лицам в собственных коммерческих целях.

При показе рекламы технические данные могут передаваться Яндексу и обрабатываться им в соответствии с правилами и политиками соответствующих рекламных сервисов.

5. Хранение и удаление данных

Разработчик не ведёт собственную серверную базу персональных данных пользователей приложения.

Данные, которые обрабатываются рекламным SDK, хранятся и удаляются в соответствии с правилами и сроками, установленными Яндексом. По вопросам обработки таких данных пользователь может обратиться к Яндексу через его официальные сервисы и каналы поддержки.

По вопросам обработки данных непосредственно разработчиком можно обратиться по адресу Alexey.panda@gmail.com.

6. Безопасность

Разработчик принимает разумные меры для предотвращения несанкционированного доступа к информации, находящейся под его контролем. Передача данных рекламным SDK осуществляется в рамках работы стороннего сервиса и регулируется его собственными техническими и организационными мерами.

7. Конфиденциальность детей

Приложение не предназначено специально для сбора персональных данных детей. Разработчик не запрашивает у пользователей сведения, позволяющие установить личность ребёнка.
