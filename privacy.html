Настоящая Политика конфиденциальности описывает, какие данные могут обрабатываться при использовании мобильного приложения «IQ Тест. Тест Равена.», для каких целей они используются и каким третьим лицам могут передаваться.

2. Какие данные обрабатывает приложение

Приложение предоставляет пользователю визуальные логические задания. Пользователь выбирает варианты ответов, после чего приложение рассчитывает результат.

Приложение не запрашивает имя, фамилию, номер телефона, адрес электронной почты, учётные данные или платёжную информацию. Регистрация учётной записи не предусмотрена.

Ответы на задания и результат теста используются для работы приложения и не передаются разработчику через собственный сервер приложения.

3. Рекламные сервисы Яндекса

В приложении используется Yandex Mobile Ads SDK для показа рекламы. SDK предоставляется компанией Яндекс и может обрабатывать технические сведения об устройстве и взаимодействии с рекламой.

В зависимости от версии SDK и настроек приложения могут обрабатываться:

  • рекламные идентификаторы устройства и другие технические идентификаторы;
  • IP-адрес и сведения, необходимые для сетевого взаимодействия;
  • информация об устройстве, операционной системе и параметрах подключения;
  • сведения о показах рекламы и взаимодействии с рекламными материалами.

Эти сведения используются для показа рекламы, оценки её эффективности, обеспечения работы рекламной системы и предотвращения недействительных рекламных действий.

Сбор сведений о местоположении зависит от настроек SDK и приложения. Если соответствующая функция не включена разработчиком, SDK не должен получать данные о местоположении через эту функцию.

Разработчик не использует рекламные данные для самостоятельного создания пользовательских профилей.

4. Передача данных третьим лицам

Разработчик не продаёт пользовательские данные третьим лицам. При показе рекламы технические данные могут передаваться Яндексу и обрабатываться им в соответствии с его политиками и условиями предоставления рекламных сервисов.

5. Хранение и удаление данных

Разработчик не ведёт собственную серверную базу персональных данных пользователей приложения.

Данные, обрабатываемые рекламным SDK, хранятся и удаляются в соответствии с правилами и сроками, установленными Яндексом. По вопросам обработки таких данных пользователь может обратиться к Яндексу через его официальные сервисы.

По вопросам обработки данных непосредственно разработчиком можно написать на Alexey.panda@gmail.com.

6. Безопасность

Разработчик принимает разумные меры для защиты информации, находящейся под его контролем, от несанкционированного доступа. Обработка данных рекламным SDK регулируется также мерами безопасности соответствующего поставщика сервиса.

7. Конфиденциальность детей

Приложение не предназначено специально для сбора персональных данных детей. Разработчик не запрашивает у пользователей сведения, позволяющие установить личность ребёнка.

8. Изменения политики

Разработчик может периодически обновлять настоящую Политику конфиденциальности. Актуальная версия размещается на этой странице. Дата последнего обновления указывается в начале документа.
